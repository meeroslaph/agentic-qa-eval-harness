# CLAUDE.md

Project context for Claude Code. The canonical guidance for AI coding
agents (commands, constraints, coding standards, what NOT to add) lives
in [AGENTS.md](AGENTS.md). Read that first.

This file exists because Claude Code reads `CLAUDE.md` by default; other
tools (Codex, Cursor, etc.) read `AGENTS.md`. Keeping both as pointers
to a single source avoids drift.
